## Brand & Style

This design system serves an enterprise-grade global Testing, Inspection, and Certification (TIC) infrastructure platform. The brand personality embodies institutional authority, metrological precision, absolute compliance, and advanced technological validation. 

The aesthetic is **Technical High-Contrast Modernism with Precision Glassmorphism accents**. It merges the uncompromising clarity of laboratory instruments with the refined execution of Tier-1 enterprise software. The experience must instill unwavering trust in multinational procurement officers, lab directors, and regulatory compliance heads.

Visual signatures include:
- Razor-sharp structural grid alignments with micro-borders (1px structural dividers).
- High-contrast data density balanced by disciplined rhythm and negative space.
- Precision frosted-glass overlays specifically designated for status monitors, compliance badges, and floating metric bars.
- High-impact industrial amber/orange focal points reserved strictly for calls-to-action, critical telemetry alerts, and verification checkpoints.

## Colors

The palette establishes an authoritative, laboratory-certified baseline using deep maritime blues offset by industrial warning pigments and technical signal accents.

### Core Roles
- **Primary Navy (`#0B192C` / `#0F172A`):** Anchors navigation panels, authoritative typography, structural footers, and foundational data tables. Imparts permanence and institutional security.
- **Secondary Industrial Amber/Orange (`#EA580C` base, `#F97316` hover):** Reserved exclusively for conversion vectors, primary CTAs, critical inspection markers, and immediate audit triggers. Never used for decorative backgrounds.
- **Tertiary Technical Cyan/Teal (`#0284C7` base, `#0EA5E9` interactive):** Communicates real-time verification status, active sensor feeds, calibration data links, and technical telemetry metrics.
- **Surface Foundation (`#FFFFFF` pure, `#F8FAFC` canvas, `#F1F5F9` sub-tier):** Crisp technical backdrop ensuring optimum legibility across complex multi-column audit reports and regulatory schemas.
- **Borders & Dividers (`#E2E8F0` structural, `#CBD5E1` active focus):** High-precision lines that delineate tabular data with surgical accuracy.

## Typography

The typographic hierarchy balances structural command with micro-scale legibility:
- **Headlines (Plus Jakarta Sans):** Geometric stability with contemporary geometric terminals. Provides distinctive corporate authority across global certification categories and core value propositions.
- **Body & Controls (Inter):** Highly legible grotesque sans-serif with tall x-height and neutral characteristics. Built for high-density metric tables, compliance statutes, and lab reports.
- **Technical Metadata (`label-mono-tech`):** Displayed in uppercase styling with positive letter tracking (`0.06em`) to present ISO standards, batch codes, certificate IDs, and instrument calibration limits.

## Layout & Spacing

The architecture operates on a responsive 12-column grid system tuned for dense technical dashboards, split-screen service audits, and multi-tier institutional showcases.

- **Desktop (1280px+):** 12 columns, 32px gutters, 64px external section margins. Maximum container constraint of 1440px ensures multi-pane telemetry readouts remain within standard visual scanning lanes.
- **Tablet (768px - 1279px):** 8 columns, 24px gutters, 32px external margins. Dynamic reflow collapses auxiliary analytical widgets into tabbed carousels.
- **Mobile (< 768px):** 4 columns, 16px gutters, 16px external margins. Key metric matrices collapse to alternating 2-column or stacked single-column cards.
- **Vertical Rhythm:** Strict adherence to 4px/8px incremental multiples (`space-xs` to `space-xl`) creates a consistent vertical cadence across data grids and form matrices.

## Elevation & Depth

This design system avoids heavy, muddy drop shadows in favor of crisp dimensional layering, low-contrast structural borders, and precision glassmorphism overlays.

### Depth Hierarchy
1. **Base Flat (Elevation 0):** Canvas `#F8FAFC` and modular panels `#FFFFFF` bounded by 1px solid borders in `#E2E8F0`. No shadow.
2. **Elevated Card (Elevation 1):** Subtle directional elevation for interactive panels:
   - Box Shadow: `0 1px 3px 0 rgba(11, 25, 44, 0.05), 0 1px 2px -1px rgba(11, 25, 44, 0.04)`.
   - Border: 1px solid `#E2E8F0`.
3. **Precision Glassmorphism (Elevation Overlay):** Reserved for contextual floating status bars, pinned inspection filters, and compliance badges:
   - Background: `rgba(255, 255, 255, 0.82)`.
   - Backdrop Blur: `12px` (with fallback saturating filters).
   - Border: 1px solid `rgba(226, 232, 240, 0.8)`.
   - Inset Highlight: `inset 0 1px 0 0 rgba(255, 255, 255, 0.9)`.
4. **Modal / Verification Overlay (Elevation 2):** Critical modal windows, interactive certificate viewers, and active popovers:
   - Box Shadow: `0 20px 25px -5px rgba(11, 25, 44, 0.1), 0 8px 10px -6px rgba(11, 25, 44, 0.05)`.
   - Border: 1px solid `#CBD5E1`.

## Shapes

The design system adopts a **Soft (Level 1)** geometric standard. This micro-radii treatment (`0.25rem` / 4px base) avoids playful roundness and conveys mechanical accuracy, industrial discipline, and architectural authority.

- **Base Radius (4px / 0.25rem):** Form inputs, default buttons, status indicators, inline tags, data grid rows.
- **Card & Modular Radius (8px / 0.5rem - `rounded-lg`):** Content cards, audit log containers, telemetry widgets.
- **Modal Radius (12px / 0.75rem - `rounded-xl`):** Dialog windows, report drawers, expanded document viewports.
- **Badge Shape:** Badges and metric pills maintain standard 4px soft corners or full pill treatment only when representing continuous machine states (e.g., live streaming feeds).

- **Primary CTA:** Background `#EA580C`, text `#FFFFFF`, font weight `600`, radius `0.25rem`, vertical padding `0.75rem`, horizontal padding `1.5rem`. Hover transitions to `#F97316` with a micro-lift (`transform: translateY(-1px)`). Active state darkens to `#C2410C`.

- **Technical Outline:** Background transparent, border `1px solid #CBD5E1`, text `#0F172A`. Hover shifts background to `#F1F5F9` and border to `#0284C7`.

### Chips & Compliance Badges
- **Status Verified:** Background `rgba(2, 132, 199, 0.08)`, border `1px solid rgba(2, 132, 199, 0.3)`, text `#0284C7`, font `label-mono-tech`.
- **Critical Action Required:** Background `rgba(234, 88, 12, 0.08)`, border `1px solid rgba(234, 88, 12, 0.3)`, text `#EA580C`.
- **Frosted Glass Badge:** Backdrop blur `8px`, background `rgba(255, 255, 255, 0.75)`, text `#0B192C`, border `1px solid rgba(226, 232, 240, 0.8)`.

### Form Fields & Inputs
- **Text Inputs:** Background `#FFFFFF`, border `1px solid #CBD5E1`, border-radius `0.25rem`, padding `0.625rem 0.875rem`, typography `body-md`.
- **Focus State:** 1px border `#0284C7`, outline `2px solid rgba(2, 132, 199, 0.2)`. No layout shift.
- **Labeling:** Top-aligned, uppercase tracking using `label-mono-tech`, color `#475569`.

### Selection Controls (Checkboxes & Radios)
- Checkbox dimensions `16px × 16px`, border-radius `2px`, border `1.5px solid #94A3B8`.
- Checked state fills with `#0B192C` featuring a sharp white checkmark icon.
- Focus ring matches `#0284C7` with a 2px offset.

### Cards & Analytical Containers
- Background `#FFFFFF`, border `1px solid #E2E8F0`, corner radius `8px`.
- Card Header: Separated by a 1px border `#F1F5F9`, featuring an integrated technical tag and ISO compliance tier.
- Hover Interaction: Subtle border shift from `#E2E8F0` to `#CBD5E1` without disruptive elevation changes.

### Domain-Specific Components
- **Certificate Verification Block:** Dual-column verified credential box with cryptographic hash preview, QR matrix anchor, real-time validity status badge, and one-click PDF download CTA.
- **Inspection Metric Matrix:** Tabular telemetry grid utilizing alternating row fills (`#FFFFFF` to `#F8FAFC`), monospaced ISO timestamps, and teal accent micro-sparklines.
